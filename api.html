2. EMI Calculation Formula API FORMULA

Calculate loan EMI for Home, Car & Personal loans.

// Example Usage
const result = ToolsHub.calculateEMI(1000000, 8.5, 240);

3. GST Tax Calculation API FORMULA

Calculate CGST, SGST, IGST inclusive & exclusive values.

ToolsHub.calculateGST(amount, ratePercent, isInclusive)
// Example Usage
const tax = ToolsHub.calculateGST(5000, 18, false);
// Returns: { original: 5000, cgst: 450, sgst: 450, total: 5900 }
