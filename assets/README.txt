AcroVault UI Asset Pack
=======================
Separated assets extracted from the generated AcroVault website-design concept.
PNG format. Some UI badges/panels are preserved as rectangular artwork; character/object assets
have an attempted transparent cutout treatment.

Note: because the source concept is a generated composite image, these are extracted artwork assets,
not official third-party logos or source files. For production, replace third-party tool logos with
their properly licensed/official assets where required.
